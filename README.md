# EDGAR Graph Database Project

This project is designed to practice graph database concepts and implementations using SEC EDGAR filing data.

## Overview

The project explores how to structure, store, and query financial data from SEC EDGAR filings using graph database technology (Neo4j). It includes schema designs, data models, and query patterns for analyzing financial information in a graph format.

## Contents

- **Documentation**: Design documents, schema diagrams, and analysis guides for working with EDGAR data in a graph database
- **Scripts**: Implementation scripts and utilities for data ingestion and processing

## Purpose

This is a learning and practice project to gain hands-on experience with:
- Graph database schema design
- Neo4j implementation patterns
- Financial data modeling
- SEC EDGAR data structure and analysis
- Vector embeddings and RAG (Retrieval Augmented Generation) patterns
